# Reporting private-data or security issues

Do not put credentials, account identifiers, source storage, real coordinates or
private screenshots in public issues. Use the repository owner's private
GitHub security reporting when available.

If a credential was exposed, revoke/rotate it with its issuer. Deleting a visible
file alone does not remove a secret from Git history, releases, caches or forks.

The companion is not a security, anti-theft or safety system. Administrator/device
authorization, private retention, explicit unknown states and no cloud credentials
or controls are intentional boundaries.
